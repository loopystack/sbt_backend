# Footer Component

## Overview
The Footer component is a comprehensive, responsive footer that provides essential information about QBiT AI Company and navigation links for the SportsBetting application.

## Technical Details

### Responsive Design
- Mobile-first approach with responsive grid layouts
- Adapts from 1 column on mobile to 4 columns on desktop
- Touch-friendly design elements

### Styling
- Uses Tailwind CSS with custom CSS variables
- Consistent with the application's design system
- Hover effects and smooth transitions
- Accent color highlights for interactive elements

### Integration
- Integrated into the main AppShell layout
- Appears on all pages of the application
- Uses React Router for navigation links

## Usage

The Footer component is automatically included in the AppShell layout and will appear on all pages. No additional configuration is required.

## Customization

To modify the footer content:
1. Edit the Footer.tsx file
2. Update company information, team details, or contact information
3. Modify the quick links or add new sections as needed
4. Update styling by modifying Tailwind classes or CSS variables

## Dependencies
- React
- React Router (for navigation links)
- Tailwind CSS
- Custom theme CSS variables
